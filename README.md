# NEXUS

**NEXUS** es un videojuego de exploración, supervivencia y combate desarrollado en C# como proyecto académico de Programación Orientada a Objetos.

## Entrega Windows Forms

La versión de interfaz gráfica se entrega como proyecto comprimido en [NexusWindowsForms/NEXUS_diseño_mejorado_sin_sql.zip](NexusWindowsForms/NEXUS_diseño_mejorado_sin_sql.zip).

El archivo contiene la solución Visual Studio, el proyecto original de consola, el proyecto Nexus.WinForms, sus formularios y documentación. Dentro del ZIP, la solución POO Nexus.slnx integra los dos proyectos. Para abrirlo, extrae el ZIP y abre esa solución en Visual Studio; selecciona Nexus.WinForms como proyecto de inicio.

**Alcance de esta entrega:** Windows Forms y juego local. No incorpora conexión ni cambios de SQL Server. La compilación local de esta versión fue confirmada por el estudiante; no se ha realizado desde aquí una compilación independiente.

## Contenido del repositorio

- POO Nexus/: proyecto original de consola.
- docs/: documentación de diseño, arquitectura y evidencias.
- NexusWindowsForms/: paquete comprimido de la entrega Windows Forms.

## Requisitos para abrir el paquete

- Windows.
- Visual Studio con el workload Desarrollo de escritorio de .NET.
- SDK de .NET 10.
