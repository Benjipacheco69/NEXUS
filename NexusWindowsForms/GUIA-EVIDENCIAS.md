# Guía de evidencias — NEXUS Windows Forms

Repositorio: https://github.com/Benjipacheco69/NEXUS  
Rama: main

Esta guía organiza las evidencias que pueden reunirse sin realizar la clonación en un segundo equipo ni la ejecución desde esa segunda clonación (etapas excluidas por el estudiante).

## Capturas que corresponden al trabajo realizado

1. Clonación inicial del repositorio, si se conserva una captura auténtica.
2. Solución original abierta en Visual Studio.
3. ZIP extraído y solución con los proyectos POO Nexus y Nexus.WinForms.
4. Interfaz Windows Forms ejecutándose localmente.
5. Commit realizado.
6. Push completado.
7. Repositorio GitHub mostrando el ZIP publicado dentro de NexusWindowsForms.

## Requisitos de las capturas

- Mostrar la fecha y hora reales del sistema operativo.
- Conservar la captura original, sin añadir fechas o resultados manualmente.
- No marcar una etapa como completada si no existe una captura auténtica.
- No utilizar capturas conceptuales como prueba de ejecución.

## Etapas excluidas

- Clonación del repositorio en una segunda máquina o entorno limpio.
- Compilación y ejecución desde esa segunda clonación.

## Registro

Completar el nombre del estudiante, fecha, hash del commit y referencias a las capturas cuando estén disponibles. Esta guía no sustituye las capturas originales.
