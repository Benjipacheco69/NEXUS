## Reglas para evidencias

- No utilizar imágenes conceptuales como si fueran capturas del programa.
- Cada captura debe indicar qué versión se ejecutó y qué funcionalidad demuestra.
- No marcar una prueba como exitosa sin haberla ejecutado.
- Mantener las capturas originales sin alteraciones que cambien el resultado observado.
