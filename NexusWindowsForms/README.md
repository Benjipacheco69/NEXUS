# NexusWindowsForms

Esta carpeta contiene el proyecto Windows Forms de NEXUS en un único archivo comprimido:

- [NEXUS_diseño_mejorado_sin_sql.zip](NEXUS_diseño_mejorado_sin_sql.zip) — paquete de proyecto completo.

## Abrir en Visual Studio

1. Descarga y extrae el ZIP.
2. Abre NEXUS/POO Nexus.slnx.
3. En el Explorador de soluciones, selecciona Nexus.WinForms como proyecto de inicio.
4. Compila y ejecuta con F5.

El ZIP contiene el proyecto original de consola y el proyecto Nexus.WinForms, además de la solución actualizada y documentación. Requiere Windows, Visual Studio con el workload de escritorio y SDK .NET 10.

## Alcance

Esta entrega no incluye conexión a SQL Server ni modificaciones de base de datos. La compilación local fue confirmada por el estudiante; la clonación en una segunda máquina y la ejecución desde esa clonación quedan fuera del alcance solicitado.
